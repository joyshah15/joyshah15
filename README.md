# Joy Shah - Portfolio Website

A modern, responsive portfolio website showcasing skills, projects, and experience.

## Features

- 🎨 **Modern Design** - Clean, professional layout with smooth animations
- 🌓 **Dark/Light Theme** - Toggle between themes with persistent storage
- 📱 **Responsive** - Mobile-first design that works on all devices
- ⚡ **Interactive** - Smooth scrolling, hover effects, and dynamic animations
- 📧 **Contact Form** - Built-in contact form with validation
- 🚀 **Fast Loading** - Optimized performance and minimal dependencies

## Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: CSS Custom Properties, Flexbox, Grid
- **Icons**: Font Awesome 6
- **Fonts**: Inter from Google Fonts
- **Features**: Local Storage, Intersection Observer API

## Setup

1. Clone or download this repository
2. Replace placeholder images in the `assets/` folder with your own:
   - `profile.jpg` (400x400) - Your profile photo
   - `about-image.jpg` (600x400) - About section image
   - `project1.jpg`, `project2.jpg`, `project3.jpg` (500x300) - Project screenshots
3. Update the content in `index.html` with your information:
   - Personal details in the hero section
   - About section content
   - Skills and technologies
   - Project descriptions and links
   - Contact information
4. Open `index.html` in a web browser

## Customization

### Colors and Theme
Edit the CSS custom properties in `styles.css` to change colors:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... other colors */
}
```

### Content
Update the following sections in `index.html`:
- Hero section: Name, title, description
- About section: Bio, stats, image
- Skills section: Technologies and tools
- Projects section: Project details, links, images
- Contact section: Email, phone, location, social links

### Projects
To add/remove projects, modify the `.projects-grid` section in `index.html` and ensure you have corresponding images in the `assets/` folder.
