# Personal Portfolio Website

A clean and modern responsive portfolio template to showcase your work and skills.

## Features

- Mobile-first, responsive design
- Smooth scrolling navigation
- Project showcase cards
- Simple contact section
- Easy to customize (just edit HTML, CSS, and images)

## Getting Started

1. **Clone or download** this repository.
2. Open `index.html` in your browser, or serve the folder using a local server:
   ```bash
   python3 -m http.server 8000
   # then visit http://localhost:8000 in your browser
   ```
3. Replace placeholder text with your own information:
   - Update name, role, and description in `index.html`.
   - Add or remove project cards as needed.
   - Update social/contact details.
4. Customize colors and layout by editing `styles.css`.

## Deploying

### GitHub Pages
1. Push the project to a GitHub repository.
2. In repository settings, enable **Pages** for the `main` branch.
3. Your site will be available at `https://<username>.github.io/<repo>/`.

### Netlify / Vercel
Upload the repository or connect your GitHub repo—no extra configuration needed.
